## 第二章 账号接入

### 2.1 登录态检测

**检测策略**：
```
1. URL 检测：
   - 未登录：URL 包含 login / passport / sso / signin
   - 已登录：URL 包含 mp.toutiao.com 且非登录页

2. Cookie 检测：
   - 头条系登录态 cookie（ttwid / uid_tt 等）

3. DOM 辅助检测：
   - 用户头像 / 昵称元素存在
   - 页面文本包含「创作中心」「数据概览」等关键词
```

### 2.2 账号信息提取

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `nickname` | `string` | 昵称 / 头条号名称 |
| `avatar` | `string` | 头像 URL |
| `platformAccountId` / `userId` | `string` | 头条号 ID |
| `fansCount` | `number?` | 粉丝数 |
| `followCount` | `number?` | 关注数 |
| `likeCount` | `number?` | 获赞 / 阅读量 |

## 第三章 微头条发布（image）

### 3.1 发布页 URL 与入口

**发布入口**：今日头条创作中心 → 左侧「微头条」菜单

微头条是今日头条的短内容形态，类似微博，支持文字 + 图片 + 话题。

### 3.2 标准发布流程

```
1. 窗口初始化 + NavigationTracker
2. loadURL 创作中心 → 导航稳定
3. detectLoggedIn + 未登录显示窗口等 120s
4. 点击「微头条」入口进入发布页
5. 填写正文（含话题标签）
6. 上传图片（如有）
7. 点击发布按钮
8. 成功信号轮询
9. 完成
```

### 3.3 页面结构

微头条发布页面包含：
- 正文输入区域（textarea 或 contenteditable）
- 图片上传入口
- 话题添加入口
- 发布按钮

### 3.4 正文填写

使用 `document.execCommand('insertText')` 方式确保 React/Vue 受控组件正确更新。

**正文组装**：内容 + `#话题1# #话题2#` 形式追加话题。

### 3.5 图片上传技术方案

**双方案**：
1. FileChooser 拦截方案（优先）— 点击图片按钮 + 拦截文件选择对话框
2. DOM.setFileInputFiles 兜底方案 — 直接定位隐藏 file input 注入文件

**上传完成确认**：等待缩略图渲染 + 图片 URL 加载完成。

### 3.6 话题标签

微头条话题通过正文内 `#话题#` 形式添加，与微博类似。

### 3.7 发布按钮与结果检测

**发布按钮**：文本为「发布」的按钮元素。

**结果检测**：
- URL 跳转到内容管理页
- body 文本命中「发布成功」「已发布」等关键词
- 弹窗提示「发布成功」

## 第六章 排错指南

| 失败现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 登录后仍判未登录 | 登录态 cookie 未写入 | 检查 detectLoggedIn 日志 |
| 微头条入口找不到 | 左侧菜单结构变化 | 检查菜单 DOM 结构 |
| 图片上传失败 | FileChooser 未拦截成功 | 检查上传按钮的选择器 |
| 正文填写后丢失 | 受控组件问题 | 确认使用了 execCommand 方式 |
| 发布后无反馈 | 结果检测条件不匹配 | 检查 URL 变化和弹窗提示 |
