## 第二章 账号接入

### 2.1 登录态检测

**检测策略**：
```
1. URL 检测：
   - 未登录：处于扫码登录页 / 登录引导页
   - 已登录：进入创作者主页 / 后台管理页

2. DOM 辅助检测：
   - 查找用户头像 / 视频号名称元素
   - 页面文本包含「创作者主页」「数据中心」等关键词
```

**微信扫码登录特殊性**：
- 微信视频号必须使用微信扫码登录
- 登录二维码有效期较短（通常 5 分钟）
- 登录后 session 有效期较长

### 2.2 账号信息提取

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `nickname` | `string` | 视频号名称 |
| `avatar` | `string` | 头像 URL |
| `platformAccountId` / `userId` | `string` | 视频号 ID / 微信号 |
| `fansCount` | `number?` | 关注数 |
| `followCount` | `number?` | 朋友在看 / 关注数 |
| `likeCount` | `number?` | 获赞数 |

### 2.3 视频号账号 ID 提取策略

按优先级依次尝试：
1. URL 路径中的用户标识
2. DOM 中含「视频号」「微信号」标签的文本提取
3. 页面 meta 信息 / 全局变量中的用户 ID

## 第三章 视频发布

### 3.1 发布页 URL 与入口

**发布入口**：微信视频号创作者主页 → 「发表」→「视频」

### 3.2 标准发布流程

```
1. 窗口初始化 + NavigationTracker
2. loadURL 创作者主页 → 导航稳定
3. detectLoggedIn + 未登录显示窗口等 120s
4. 点击「发表」→「视频」入口
5. 上传视频（CDP FileChooser 方案）
6. 等待上传 + 转码完成
7. 填写标题 / 描述 / 话题
8. 设置封面（可选）
9. 点击发布按钮
10. 成功信号轮询
11. 完成
```

### 3.3 视频上传技术方案

使用 CDP FileChooser 方式：
- Page.setInterceptFileChooserDialog 开启拦截
- 点击上传按钮触发文件选择
- handleFileChooser 接收文件路径
- 等待上传进度完成

### 3.4 表单填写

| 字段 | 限制 | 填写方式 |
|:---|:---:|:---|
| 标题 | 平台限制 | execCommand 方式 |
| 描述 | 平台限制 | execCommand 方式 |
| 话题 | 平台限制 | 正文追加 #话题# 形式 |

### 3.5 发布按钮与结果检测

**发布按钮**：文本为「发表」/「发布」的按钮。

**结果检测**：
- URL 跳转到内容管理页
- 弹窗提示「发表成功」
- 视频出现在「已发表」列表中

## 第六章 核心技术要点

### 6.1 微信扫码登录特殊性

| 特性 | 说明 |
|:---|:---|
| 必须扫码 | 不支持账号密码登录，必须使用微信扫码 |
| 二维码有效期 | 通常 5 分钟，过期需刷新 |
| 登录态持久化 | cookie 有效期较长，可跨会话保留 |
| 多端同步 | 手机端退出可能影响网页端登录态 |

### 6.2 微信生态风控注意事项

- 频繁操作可能触发安全验证
- 建议添加适当的操作间隔
- 登录态异常时需要用户重新扫码

## 第七章 排错指南

| 失败现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 扫码后仍未登录 | 二维码过期 / 网络问题 | 刷新页面重新扫码 |
| 发布按钮找不到 | 页面结构变化 / 入口层级变化 | 检查 DOM 结构 |
| 上传无响应 | FileChooser 未拦截成功 | 检查上传按钮选择器 |
| 登录态频繁失效 | 微信风控 / 多端冲突 | 减少操作频率，手动重新登录 |
| 表单填写后消失 | React 受控组件问题 | 确认使用 execCommand 方式 |
