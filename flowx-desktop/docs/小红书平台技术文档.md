- 存在账号名称元素（`.account-name` / `.nickname` 等）

**登录关键词数组**：
```typescript
const LOGIN_KEYWORDS = [
  '创作中心', '数据中心', '作品管理',
  '发布笔记', '发布视频', '粉丝', '数据分析',
];
```

- `nickname`：用户昵称
- `avatar`：头像 URL
- `platformAccountId`：小红书号

## 第三章 视频发布

### 3.1 发布页 URL 与页面结构

**发布页 URL**：`https://creator.xiaohongshu.com/publish/publish`

该 URL 同时支持视频发布和图文发布。页面会根据上传的文件类型自动切换模式。上传视频文件后自动进入视频发布模式。

**核心 DOM 结构**：

```html
<!-- 文件上传区域 -->
<div class="upload-wrapper">
  <input type="file" accept="video/*" />
  <button class="d-button">上传视频</button>
</div>

<!-- 标题输入框 -->
<input type="text" placeholder="填写标题会有更多赞哦" />

<!-- 正文编辑区（ProseMirror 富文本） -->
<div class="ProseMirror" contenteditable="true" role="textbox"></div>

<!-- 发布按钮（Closed Shadow DOM） -->
<xhs-publish-btn submit-text="发布笔记" save-text="暂存离开">
  <!-- #shadow-root (closed) -->
  <div class="publish-page-publish-btn">
    <button class="ce-btn bg-red">发布笔记</button>
  </div>
</xhs-publish-btn>
```

### 3.2 标准发布流程

```
1. 窗口初始化 (makePublishWindow)
   └─> BrowserWindow（sandbox + contextIsolation + partition）
   └─> attachNavigationTracker(win, log)

2. 导航到发布页
   └─> win.loadURL('https://creator.xiaohongshu.com/publish/publish')
   └─> tracker.waitForStable(1500, 15000)

3. 登录态检测
   └─> evalJS(win, buildDetectLoggedInScript(LOGIN_KEYWORDS), '检测登录')

4. 文件上传（CDP）
   └─> uploadViaCDP(win, files, log, contentType='video')
   └─> waitForUploadComplete(win, log) 轮询检测

5. 填写标题（20 字限制）
   └─> execCommand('insertText') 模拟原生输入

6. 填写正文（ProseMirror，1000 字限制）
   └─> 逐行 insertText + 话题追加

7. 点击发布按钮（三层策略）
   └─> 第一层：JS click()
   └─> 第二层+第三层：CDP 穿透 shadow DOM

8. 发布结果检测
   └─> URL 跳转到 /home 或显示发布成功

9. 完成/清理
   └─> 成功：win.destroy() 自动关闭
   └─> 失败：保持窗口打开
```

### 3.3 核心难点：Closed Shadow DOM 发布按钮

**问题**：`<xhs-publish-btn>` 是自定义 Web Component，内部 shadow DOM 对外封闭。

```javascript
// ❌ 失败：JS click() 不生效
const btn = document.querySelector('xhs-publish-btn');
btn.click();
// 事件监听器绑定在 shadow DOM 内部的 <button> 上
```

**解决方案：CDP 穿透**：
1. `CDP.DOM.getDocument({ pierce: true, depth: -1 })` — 穿透 shadow DOM
2. 遍历所有节点，收集 `<button>` 元素
3. `CDP.DOM.getBoxModel(nodeId)` 获取坐标
4. `CDP.Input.dispatchMouseEvent` 合成鼠标事件

### 3.4 核心难点：按钮禁用 + 视口检测

**问题**：`xhs-publish-btn` 在视口外时 `submit-disabled="true"`，组件内部的 watcher 只在 `scroll` 事件触发时重新检查表单完整性。

**解决方案**：每次轮询前先调用 `element.scrollIntoView({ block: "center" })`，再检查属性。

**效果对比**：

| 阶段 | 修复前 | 修复后 |
|:---|:---|:---|
| 从填写完成到按钮可用 | ~13 秒 | ~1-2 秒 |
| 发布总时长 | ~28 秒 | ~15 秒 |

### 3.5 发布按钮坐标 — 左右两个按钮布局

```
host rect: left=272, top=771, width=680, height=90

  left=272                    center=612                 right=952
     |                           |                         |
     ┌───────────────────────────┬──────────────────────────┐
     |       暂存离开            |        发布（bg-red）    |
     |     ce-btn white          |      ce-btn bg-red       |
     └───────────────────────────┴──────────────────────────┘
         ↑ 50% 位置: 草稿!         ↑ 75% 位置: 真正的发布按钮!
```

**解决方案**：点击坐标固定为 host 元素 **x + width \* 0.75**，y = center。

### 3.6 发布后验证逻辑

点击后 5 秒内检测页面状态：

| 判定条件 | 结果 |
|:---|:---|
| `hasSuccessText = true` | ✅ 发布成功 |
| `leftPublishPage = true` | ✅ 跳转到 /publish/success |
| `hasDraftText = true` | ⚠️ 误点了草稿按钮 |
| `hasConfirmText = true` | ⚠️ 需要二次确认弹窗 |
| `hasErrorText = true` | ❌ 有错误提示 |

### 4.2 完整发布流程

```
1. 窗口初始化 → makePublishWindow(accountId)
2. 导航到发布页 → tracker.waitForStable
3. 登录态检测 → evalJS(buildDetectLoggedInScript)
4. 文件上传（CDP） → uploadViaCDP + waitForUploadComplete
5. 填写标题 → buildFillTitleScript（20 字限制）
6. 填写正文 → buildFillContentScript（ProseMirror，1000 字）
7. 点击发布按钮 → 三层策略（JS + CDP 穿透）
8. 发布结果检测 → URL 跳转或成功文本
9. 完成/清理 → 成功自动关窗
```

### 4.3 核心难点：ProseMirror 富文本填写

**问题**：ProseMirror 有内部的 `state.doc` 数据模型，直接设置 `innerText` 不会更新 state。

**解决方案**：`document.execCommand('insertText')` 模拟原生输入

```javascript
// 逐行 insertText：
target.focus();
document.execCommand('selectAll');
document.execCommand('delete');

var lines = fullText.split('\n');
for (var j = 0; j < lines.length; j++) {
  if (lines[j]) {
    document.execCommand('insertText', false, lines[j]);
  }
  if (j < lines.length - 1) {
    document.execCommand('insertText', false, '\n');
  }
}
```

**关键洞察**：ProseMirror 监听浏览器原生 `input` 事件来更新内部 `state.doc`。`execCommand('insertText')` 会触发原生 `input` 事件。

### 4.4 核心难点：React 受控组件标题被清空

**问题**：小红书标题输入框是 React 受控组件。直接设置 `input.value` 不会更新 state，下次 React 重渲染时标题被清空。

**解决方案**：用 `execCommand('insertText')` 代替直接赋值，触发原生 `input` 事件 → React 调用 `onChange` → `setState` 更新。

### 4.5 字数与标签限制

| 标题 | 20 字 | 超过自动截断，记录 warning |
| 正文 | 1000 字 | 超过自动截断，记录 warning |
| 话题 | 最多 10 个 | 超过自动截断前 10 个 |

## 第五章 文章发布（article）

### 5.1 发布入口与图文/视频的差异

**发布入口**：`https://creator.xiaohongshu.com/publish/publish?source=official&from=menu&target=article`

| 维度 | 图文发布（image） | 文章发布（article） |
|:---|:---|:---|
| 入口 URL | 同默认发布页，需检测 tab 切换 | `?target=article` 专用参数 |
| 编辑模式 | 填写标题 + 正文 + 上传封面 → 点击"发布笔记" | 点击"新的创作" → 编辑正文 → 一键排版 → 下一步 → 填写摘要+话题 → 发布 |
| 标题限制 | 20 字 | **64 字** |
| 正文限制 | 1000 字 | **无限制** |
| 话题标签 | 最多 10 个，追加在正文末尾 | 最多 10 个，在**第三步摘要描述框**中添加 |
| 文章摘要 | 无 | **第三步页面填写，ProseMirror 编辑器** |
| 封面图 | 必填 | 可选（排版阶段自动生成或上传） |
| 发布按钮 | `xhs-publish-btn`（shadow DOM） | `xhs-publish-btn`（shadow DOM） |

### 5.2 核心流程（多步点击）

```
1) loadURL(?target=article)
     ↓
2) 检测是否已在编辑器中
   - hasTitleInput: 检测是否存在 <textarea>
   - hasEditor: 检测是否存在 contenteditable 的 ProseMirror
   - createCount: 检测"新的创作"按钮可见性
     ↓
3) 不在编辑器？ → 点击"新的创作"按钮进入编辑器
     ↓
4) 填写标题（64 字限制）
   buildFillTitle(title, ARTICLE_TITLE_LIMIT=64)
     ↓
5) 填写正文（无字数限制，ProseMirror 富文本编辑器）
   buildFillContent(content, null)
     ↓
6) 🔑 多步点击发布流程（3 步）
   ├─ 第 1 步：点击"一键排版"
   │   - 按钮: button.ce-btn.bg-red
   │   - 等待排版完成（轮询 button 文本变化）
   │   - 按钮文本从"一键排版"→"下一步"
   │
   ├─ 第 2 步：点击"下一步"
   │   - 等待页面导航稳定（waitForStable 5 秒）
   │
   ├─ 第 2.5 步：填写文章摘要 + 话题标签（第三步页面）
   │   - 摘要框：第二个 ProseMirror / tiptap 编辑器
   │   - 话题标签：在摘要描述框中通过 CDP 方式插入
   │
   └─ 第 3 步：点击"发布"
       - 按钮在 closed shadow DOM 中: <xhs-publish-btn>
       - 必须通过 CDP 深度扫描（pierce:true）穿透 shadow DOM
          ↓
7) 等待发布结果（60 秒超时）
   探测 URL: /publish/success 或 published=true
```

### 5.3 文章摘要技术方案

小红书文章发布的第三步（发布设置页）有一个**正文描述框**，用于填写文章摘要。

**结构特征**：
- 也是 ProseMirror / tiptap 编辑器（与正文编辑器类型相同）
- 外层有 `.editor-container` 和 `.tiptap-container` 容器
- placeholder 在内部 `<p>` 标签的 `data-placeholder` 属性上
- 页面上有**两个** ProseMirror 编辑器：第一个是正文编辑器，第二个是摘要描述框

**识别策略**：
1. 收集所有 ProseMirror / tiptap 编辑器
2. 如果有 2 个及以上，取第二个作为摘要描述框
3. 如果只有 1 个（边界情况），就用那一个

### 5.4 话题标签：正文 vs 摘要

| 发布类型 | 话题位置 | 插入方式 |
|:---|:---|:---|
| 图文发布 | 正文末尾追加 | CDP 方式（空格分隔插入） |
| 视频发布 | 标题/描述末尾追加 | CDP 方式 |
| **文章发布** | **第三步摘要描述框末尾追加** | **CDP 方式（空格分隔插入）** |

**重要**：文章发布的话题不在第一步的正文编辑器中添加，而是在第三步的摘要描述框中添加。

## 第六章 排错指南

### 6.1 登录 / 授权相关

| 现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 扫码成功但仍判定「未登录」 | Cookie 未写入当前 partition | 检查 `detectLoggedIn` 日志的 `matchedKeywords` |
| 一直停在登录页不跳转 | 小红书风控：需要二次验证 | 登录窗口保持打开，等用户手动完成验证 |

### 6.2 发布相关

| 失败现象 | 可能原因 | 排查 |
|:---|:---|:---|
| 发布按钮禁用一直循环到超时 | 视频/图片没上传完成 / 标题或正文为空 | 检查 `poll-content-fields` 返回值 |
| shadow DOM 中搜到 0 个按钮 | CDP DOM 搜索未打开 pierce:true | 确认 `pierce: true` 参数 |
| 右半部分候选按钮: 0 个 | 发布按钮 class 改了 | 放宽搜索条件，查看所有按钮的 class |
| 点击后 URL 没变 | 点错了按钮（可能点了"暂存离开"）| 检查命中按钮的坐标是否在右侧 75% |
| ProseMirror 填写后被清空 | 没用 execCommand，state 未同步 | 确认 method 为 `prosemirror` |
| 标题填写后被清空 | React 受控组件，没用 execCommand | 确认标题填写使用了 `insertText` 方式 |

### 6.3 调试技巧

1. **打开 DevTools**：发布窗口 `F12` 或右键 → 检查
2. **验证 shadow DOM**：在 DevTools Elements 面板，点击 `<xhs-publish-btn>` 展开 shadow root
3. **验证 ProseMirror**：`document.querySelector('.ProseMirror')`
4. **验证标题选择器**：查找 placeholder 含"标题"的 input

## 第七章 架构演进

### 7.1 PlatformDispatcher 工厂方法模式

```typescript
// 两级分发
export function createExecutor(
  platform: string,
  contentType: 'video' | 'image' | 'article',
): PublishExecutor {
  const adapter = getPlatformAdapter(platform);
  switch (contentType) {
    case 'video':   return { execute: adapter.publishVideo || adapter.publish };
    case 'image':   return { execute: adapter.publishImage || adapter.publish };
    case 'article': return { execute: adapter.publishArticle || adapter.publish };
  }
}
```

### 7.2 代码隔离与共享模块

**共享模块**：
| 共享模块 | 说明 |
|:---|:---|
| `buildFillTitle()` | 标题填写函数（不同字数限制由参数控制） |
| `buildFillContent()` | 正文内容填充（支持 ProseMirror） |
| `cdpClickPublishButton()` | CDP 穿透 shadow DOM 点击 |
| `waitForStable` / `attachNavigationTracker` | 页面导航稳定检测 |

**独立实现**：
| 独立实现 | 说明 |
|:---|:---|
