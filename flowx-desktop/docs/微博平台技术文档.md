## 第二章 账号接入

### 2.1 登录态检测（detectLoggedIn）— 四重验证

```
1. Cookie 检测（最高优先级）：SUB cookie 存在且非空 → 已登录
   （辅助：SUBP cookie、WEIBOCN_WM、_2AAM 等 session 标识）
2. URL 检测：当前页处于 weibo.com/login / passport.weibo.com / sso.weibo.com → 未登录
3. 域名检测：当前 URL 属于 me.weibo.com 或 weibo.com/u/、weibo.com/p/ 且非登录页 → 加分项
4. DOM 辅助检测：查找用户信息元素 + 页面文本关键字
```

### 2.2 核心登录凭证 Cookie

| Cookie 名称 | 作用 |
|:---|:---|
| `SUB` | **核心登录态凭证**（最关键，存在且非空即可认为已登录） |
| `SUBP` | 辅助登录标识（手机端/第三方登录场景） |
| `WEIBOCN_WM` / `_2AAM` | 微博国际版 / 新版登录的 session 标识（辅助判定） |

**URL 判定规则**：
```typescript
// 未登录：处于登录域
isLoginPage = currentUrl.includes('/login')
           || currentUrl.includes('/signin')
           || currentUrl.includes('passport.weibo.com')
           || currentUrl.includes('sso.weibo.com');

// 登录成功：进入创作中心 / 个人主页 / 上传页
inBackend = (currentUrl.includes('me.weibo.com')
         || currentUrl.includes('weibo.com/u/')
         || currentUrl.includes('weibo.com/p/')
         || currentUrl.includes('weibo.com/upload/'))
         && !isLoginPage;
```

**最终判定**：`loggedIn = !!SUB && !isLoginPage`（Cookie 优先）

### 2.3 账号信息提取（extractPageInfo）

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `nickname` | `string` | 昵称 |
| `avatar` | `string` | 头像 URL（http → https 强制升级） |
| `platformAccountId` / `userId` | `string` | 微博号（自定义字母数字）或 UID（纯数字 5-12 位） |
| `fansCount` | `number?` | 粉丝数 |
| `followCount` | `number?` | 关注数 |
| `likeCount` | `number?` | 获赞 / 转评赞 / 收藏总数 |

### 2.4 字符安全净化（Guarding）

四层严格净化：
1. **QUOTE_LIKE_CHARCODES（28 种类引号字符黑名单）**
2. **控制字符替换** — `\t \n \r \v \f` → 空格，连续空白合并
3. **URL 规范化** — `//xxx` 补 `https:`，杂糅文本中正则提取 `https?://` URL
4. **微博自有域名强制升级 http→https**

**微博强制 HTTPS 域名白名单**：
```
weibo.com, weibo.cn, sinaimg.cn, sina.com.cn,
weibocdn.com, h5.sinaimg.cn,
ss1.bdstatic.com, ss2.bdstatic.com, ss3.bdstatic.com
```

### 2.5 平台账号 ID 提取策略

按优先级依次尝试：

| 策略 | 说明 |
|:---|:---|
| **URL weibo.com/u/{uid}** | 个人主页路径 `/u/` 后提取 5-12 位数字 |
| **URL weibo.com/p/xxxxx/{uid}** | 公众页 / 官方主页路径中的 UID |
| **DOM 提取 `a[href*="weibo.com/u/"]`** | 遍历页面链接，从 `href` 中提取 |
| **body 文本匹配「微博号：xxx」** | 正则 `/(?:微博号|微博账号|微号)[：:\s]*([A-Za-z0-9_\-]{3,30})/` |

> 注意：微博号可以是纯数字 UID，也可以是用户自定义的字母+数字组合。

### 2.6 粉丝/关注/获赞数提取

**双路径方案**：

#### 路径 A：DOM class 含 `number` / `count` / `num` 的数字元素 + 兄弟 label 配对
- 遍历所有 `[class*="number"], [class*="count"], [class*="num"]` 元素
- 关键词匹配：粉丝→fansCount、关注→followCount、获赞/点赞/收藏/转评赞→likeCount
- 支持「万 / 千 / 百 / 亿」后缀换算

#### 路径 B：body 全文正则双向兜底

如粉丝数：
```
标签在前：/(粉丝|粉丝数)[^0-9]{0,5}(\d+(?:\.\d+)?[万千百亿]?)/
标签在后：/(\d+(?:\.\d+)?[万千百亿]?)[^0-9]{0,5}(粉丝|粉丝数)/
```

### 2.7 健康检测 / 刷新账号 / 打开创作中心

| 操作 | 行为 |
|:---|:---|
| **刷新账号** | 在旧 partition 中重新 `loadURL(homeUrl)` → 等稳定 → detectLoggedIn → extractPageInfo → 覆盖保存 SecureStore |
| **打开创作中心** | 新 BrowserWindow 独立 partition 注入 account cookies → loadURL(homeUrl) |
| **健康检测** | 每 7 天或手动触发：loadURL(homeUrl) → waitForStable → detectLoggedIn；失败状态置为 expired |
| **删除账号** | SecureStore 移除记录 + 删本地头像文件 |

### 3.3 视频上传（uploadWeiboVideo）

**双方案**：

| 方案 | 做法 |
|:---|:---|
| 方案 A：FileChooser 拦截 | `Page.setInterceptFileChooserDialog` + 点「上传视频」按钮 + `handleFileChooser(action:'accept', files)` |
| 方案 B：临时 input drop | 临时 input → CDP 注入 → drop 到拖放区，不解除任何 display:none，临时 DOM 放 left:-99999 opacity:0.01 |

### 3.4 等待上传 + 封面生成

**上传完成**：进度文案消失 / 上传完成 DOM 状态 / 发布按钮解除 disabled

**封面生成等待（新增 2 分钟轮询，每 2s）**：
- 容器存在：`._a5rt_1gx9k_237` / `._a5list_1gx9k_304`
- 有效 img >= 1：`src` 非空、匹配 `wx*.sinaimg.cn` / `tvax*.sinaimg.cn`
- 已选图：`._a5itemcurr_1gx9k_367 img src` 非空

**超时策略**：2 分钟仍未就绪时**不直接失败**，继续填写表单。因为有些宽松校验场景下封面可以发布后补。

### 3.5 表单填写（严格顺序）

**顺序**：原创类型 → 标题 → 分类 → 正文

1. **选「原创」radio** — 遍历 `woo-radio-main` 内文本=原创
2. **写标题** — `input[placeholder="填写标题（0～30个字）"]`，截断到 30 字
3. **选分类** — `wbpro-select._sort_19x8d_` → 展开 → 优先 VLOG/生活，若有二级继续点二级
4. **写正文** — 只写 `content + tags`（**永远不再重复写标题**，避免重复显示）

### 3.6 发布按钮点击

**优先级**：
1. 精确匹配：`button._btn1_2z30i_72` / `[class*="_btn_2z30i_68"]` / `[class*="_btn1_2z30i_"]`
2. 文本匹配："立即发布/发布"，但绝对排除黑名单（再发一条/上传视频/上传封面/暂停/继续/删除/上传字幕/裁剪封面/视频管理）
3. 测试模式：补可见性兜底探针（offsetParent===null 场景）

### 3.7 成功信号轮询（180s）

**成功条件（任一）**：
- URL 变化：跳离 upload/channel 或命中 `/status|profile|mblog|publishSuccess/`

**失败关键词**：发布失败|不符合|违规|字数超限|未通过|请先登录|登录状态已失效

## 第六章 核心难点与解决方案

### 6.1 两个 URL 登录态判定相互误判

**问题**：视频发布页 `weibo.com/upload/channel` 不在原先的创作中心白名单里，导致误判「未登录」。

**解决方案**：在 `detectLoggedIn` 中新增 `inUploadPage` 白名单：
```typescript
const inUploadPage = currentUrl.includes('weibo.com/upload/');
const inBackend = ... || inUploadPage;
```

**相关日志标记**：`matchedKeywords: 'in-upload-page'`

### 6.2 真实隐藏 input 的 display:none 问题

**问题**：所有真实隐藏 input 外层有多层 `display:none`。解除父级 display:none 会导致页面布局完全混乱。

**解决方案**：
- 直接注入到真实隐藏 input 本体（DOM.setFileInputFiles）
- 上传成功必须用组件自己的渲染结果（缩略图）判真
- ❌ 禁止任何解除 display:none 的操作

### 6.3 FileChooser handleFileChooser 失败

**问题**：某些 Electron/Chromium 版本要求回传时必须带 `frameId` + `backendNodeId`。

**解决方案**：
```typescript
const cmdArgs = { action: 'accept', files: imageFiles } as any;
if (params.frameId)       cmdArgs.frameId       = params.frameId;
if (params.backendNodeId) cmdArgs.backendNodeId = params.backendNodeId;
```

超时时长从 12s → 18s，失败时立即降级到方案 C。

### 6.4 视频发布必须等封面生成

**问题**：上传完成但视频解码未完成时，封面候选图仍不存在，发布按钮被平台自己置为 disabled。

**解决方案**：专门的封面等待阶段（最多 2 分钟），检测 10 张候选封面 + 当前选中项。

### 6.5 发布按钮 offsetParent 误判不可见

**问题**：`offsetParent !== null` 判定可见的方法在微博按钮（位于 fixed/absolute 父级容器）失效，offsetParent 恒等于 `null`。

**解决方案**：再补一层兜底扫描：
```javascript
getComputedStyle(el).display  !== 'none' &&
getComputedStyle(el).visibility !== 'hidden' &&
getBoundingClientRect().width > 1 && height > 1
```

## 第七章 排错指南

### 7.1 登录 / 授权相关

| 现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 扫码后仍判定「未登录」 | `SUB` cookie 未写入当前 partition | 检查 `detectLoggedIn` 日志的 `matchedKeywords`，确认 `SUB-cookie` 是否出现 |
| 登录完成后跳回登录页 | 微博风控：异地 / 新设备 / 需要手机二次验证 | 保持窗口打开，让用户手动完成验证；检查 URL 是否含风控码 |
| 登录页加载不出来 | 微博强制 https，部分资源路径可能被代理拦截 | 看控制台 Network，确认 `*.weibo.com`、`*.sinaimg.cn` 域名不被误拦截 |

### 7.2 图文图片上传相关

| 现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 注入成功但没图片 | 旧方案的假成功（没触碰到真实 input） | 看日志 45s 内「缩略图校验中」的 validImgs |
| FileChooser 失败报错 `No node with given id` | 老 Electron CDP 要 frameId + backendNodeId | 看 log 的 `params=...`，确认两个 param 已带回 |
| 45s 仍没有缩略图 | 真实隐藏 input 被选错 | 看 `[C] 定位 input: {...}` 日志中 nodes 的 class/accept |
| 图片有了但「发送」按钮 disabled | 正文仍空 / 上传中 / 平台风控提示 | 控制台打 `$0.disabled` 看按钮，检查页面有无红色提示 |

### 7.3 视频上传相关

| 现象 | 可能原因 | 排查 |
|:---|:---|:---|
| upload/channel 明明已登录仍判未登录 | 旧版白名单漏了 upload 路径 | 看 `matchedKeywords` 是否含 `in-upload-page` |
| 分类/封面未就绪就写标题导致按钮 disabled | 填写顺序不对 | 已经固定为：原创 → 标题 → 分类 → 正文 |
| 正文显示出 2 次标题 | 旧版把标题也写入了正文 | 正文只拼 content + tags，不重复带标题 |
| 测试模式找不到发布按钮但实际存在 | offsetParent 兜底脚本未命中 / button class 新 hash | 补充精确 hash 选择器 |
