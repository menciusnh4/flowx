## 二、登录态检测（detectLoggedIn）

### 2.1 检测优先级（四重验证）

```
1. Cookie 检测（最高优先级）：SUB cookie 存在且非空 → 已登录
   （辅助：SUBP cookie、WEIBOCN_WM、_2AAM 等 session 标识）
2. URL 检测：当前页处于 weibo.com/login / passport.weibo.com / sso.weibo.com → 未登录
3. 域名检测：当前 URL 属于 me.weibo.com 或 weibo.com/u/、weibo.com/p/ 且非登录页 → 加分项
4. DOM 辅助检测：查找用户信息元素 + 页面文本关键字（"创作中心"/"内容管理"/"发微博"/"退出登录"等）
```

### 2.2 核心登录凭证 Cookie

| Cookie 名称 | 作用 |
|:---|:---|
| `SUB` | **核心登录态凭证**（最关键，存在且非空即可认为已登录） |
| `SUBP` | 辅助登录标识（手机端/第三方登录场景） |
| `WEIBOCN_WM` / `_2AAM` | 微博国际版 / 新版登录的 session 标识（辅助判定） |

### 2.3 URL 判定规则

```typescript
// 未登录：处于登录域
isLoginPage = currentUrl.includes('/login')
           || currentUrl.includes('/signin')
           || currentUrl.includes('passport.weibo.com')
           || currentUrl.includes('sso.weibo.com');

// 登录成功：进入创作中心 / 个人主页
inBackend = (currentUrl.includes('me.weibo.com')
         || currentUrl.includes('weibo.com/u/')
         || currentUrl.includes('weibo.com/p/'))
         && !isLoginPage;
```

### 2.4 DOM 辅助检测（executeJavaScript）

在页面上检查以下元素/文本：

| 检查项 | 说明 |
|:---|:---|
| 昵称元素 | `.user-info .name` / `.username` / `.screen-name` / `[class*="user-name"]` / `[class*="nickname"]` / `.WD_header_name` |
| 页面关键字 | 「创作中心」「内容管理」「数据中心」「粉丝」「发微博」「发布」「收益管理」「退出登录」「我的主页」 |
| 组合判断 | 有昵称元素 **或** (有「退出登录」+ 有至少一个菜单关键字) → 视为 DOM 已登录 |

### 2.5 返回的 LoginCheckResult

- `loggedIn = !!SUB && !isLoginPage`（Cookie 优先）
- `matchedKeywords`：汇总所有命中的 cookie 名 + URL 标志 + DOM 标志

## 三、账号信息提取（extractPageInfo）

### 3.1 提取范围

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `nickname` | `string` | 昵称 |
| `avatar` | `string` | 头像 URL（http → https 强制升级） |
| `platformAccountId` / `userId` | `string` | 微博号（自定义字母数字）或 UID（纯数字 5-12 位） |
| `fansCount` | `number?` | 粉丝数 |
| `followCount` | `number?` | 关注数 |
| `likeCount` | `number?` | 获赞 / 转评赞 / 收藏总数（取页面可拿到的字段） |

### 3.2 字符安全净化（Guarding）

同 B 站适配器，四层严格净化：

1. **QUOTE_LIKE_CHARCODES（28 种类引号字符黑名单）**
2. **控制字符替换** — `\t \n \r \v \f` → 空格，连续空白合并
3. **URL 规范化** — `//xxx` 补 `https:`，杂糅文本中正则提取 `https?://` URL
4. **微博自有域名强制升级 http→https**

#### 微博强制 HTTPS 域名白名单：
```
weibo.com, weibo.cn, sinaimg.cn, sina.com.cn,
weibocdn.com, h5.sinaimg.cn,
ss1.bdstatic.com, ss2.bdstatic.com, ss3.bdstatic.com
```

### 3.3 平台账号 ID（platformAccountId）提取策略

按优先级依次尝试：

| 策略 | 说明 |
|:---|:---|
| **URL weibo.com/u/{uid}** | 个人主页路径 `/u/` 后提取 5-12 位数字 |
| **URL weibo.com/p/xxxxx/{uid}** | 公众页 / 官方主页路径中的 UID |
| **DOM 提取 `a[href*="weibo.com/u/"]`** | 遍历页面链接，从 `href` 中提取 |
| **body 文本匹配「微博号：xxx」** | 正则 `/(?:微博号|微博账号|微号)[：:\s]*([A-Za-z0-9_\-]{3,30})/` |

> 注意：微博号可以是纯数字 UID，也可以是用户自定义的字母+数字组合（`[A-Za-z0-9_-]{3,30}`）。

### 3.4 昵称提取选择器

[class*="user-name"] / [class*="nickname"] / [class*="screen-name"]

```
img[class*="avatar"] / img[class*="head"]
a[href*="weibo.com/u/"] img / a[href*="weibo.com/p/"] img
.avatar img / a.avatar img / img.avatar
.user-info img / .header img / .topbar-user img

```

### 3.6 粉丝/关注/获赞 数提取

双路径方案（同 B 站）：

#### 路径 A：`[class*="number/count/num"]` + 兄弟 label 配对
- 关键词匹配：粉丝→fansCount、关注→followCount、获赞/点赞/收藏/转评赞→likeCount
- 支持「万 / 千 / 百 / 亿」后缀换算

#### 路径 B：body 全文正则双向兜底（每个字段 2 条正则）

```
标签在前：/(粉丝|粉丝数)[^0-9]{0,5}(\d+(?:\.\d+)?[万千百亿]?)/
标签在后：/(\d+(?:\.\d+)?[万千百亿]?)[^0-9]{0,5}(粉丝|粉丝数)/
```

### 3.7 诊断日志

适配器在 `extractPageInfo` 返回前会输出一条结构化诊断日志（便于调试）：

```
FINAL RETURN → avatar.len={N}, avatar="{前160字符}", nickname="...",
               platformAccountId="...", fans=X, follow=Y, like=Z
```

如果头像疑似仍包含异常字符（如引号），还会额外输出 **[CHARCODE] guardAvatar 疑似仍有异常字符** 日志，打印前 6 个 + 后 6 个字符的 Unicode 码位，便于快速定位应补充哪些黑名单字符。

### 4.2 视频发布流程（runWeiboPublish）

完整 9 步：

```
1. 窗口 + NavigationTracker
     发布 URL: https://weibo.com/upload/channel
2. 登录检测
     未登录时弹窗给用户 120 秒手动登录，登录后重走流程
3. 过滤视频文件（支持 mp4/mov/mkv/avi/flv/wmv/webm/m4v/mpg/mpeg/3gp）
4. uploadWeiboVideo
     方案 A：FileChooser 拦截 + 点「上传视频」按钮（精确 class 哈希）
     方案 B：临时 input + drop（不触碰 display:none）
5. waitForUploadComplete（最长 6 分钟）：进度文案消失
6. 等待封面生成（最长 2 分钟）：
     ._a5rt_1gx9k_237 出现 + 10 张候选项有效图片 >=1 + ._a5itemcurr_1gx9k_367 当前选中
7. 表单填写（严格顺序）：
     原创类型 → 标题(≤30) → 分类(VLOG/生活+二级) → 正文（只 content+tags，不重复带标题）
8. 点击发布：精确匹配 button._btn1_2z30i_72 / [._btn_2z30i_68]，文本黑名单过滤
9. 成功信号轮询（最长 180s）：
     成功：URL 跳离 upload/channel 或 body 命中发布成功/发送成功
     失败：命中「不符合/违规/字数超限/未通过/请先登录」
```

## 六、排错指南

### 6.1 登录 / 授权相关

| 现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 扫码后仍判定「未登录」 | `SUB` cookie 未写入当前 partition | 检查 `detectLoggedIn` 日志的 `matchedKeywords`，确认 `SUB-cookie` 是否出现 |
| 登录完成后跳回登录页 | 微博风控：异地 / 新设备 / 需要手机二次验证 | 保持窗口打开，让用户手动完成验证；可检查 URL 是否含 `retcode=50023003` 等风控码 |
| 登录页加载不出来 | 微博强制 https，部分资源路径可能被阻断 | 看控制台 Network，确认 `*.weibo.com`、`*.sinaimg.cn` 域名不被代理误拦截 |

### 6.2 信息提取相关

| 现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 昵称/头像为空字符串 | `me.weibo.com` DOM 实际结构与预估选择器不一致 | 打开授权窗口 DevTools，在 Console 中逐一验证 `nicknameSelectors` / `avatarSelectors` 数组里的选择器，把命中的排到最前面 |
| 平台账号 ID 没取到 | 用户只有自定义微博号（非纯数字 UID），URL 里也没包含路径 | 检查 body 文本里是否有「微博号：xxx」格式；若 DOM 中有其他元素保存 UID，追加到提取脚本 |
| 头像 URL 带了中文引号或特殊字符 | 属性值被模板字符串拼接时混入了文本 | 查看 `[CHARCODE] guardAvatar` 诊断日志，找出异常字符的 Unicode，追加到 `QUOTE_LIKE_CHARCODES` Set |
| 粉丝/关注数一直为 null | 创作中心「数据中心」模块 DOM 类名不是 `number/count/num` | 手动打开页面，看数据卡片的数字是哪个 class，把 class 关键词追加到 DOM 遍历的选择器中 |

### 6.3 调试技巧

1. **打开授权窗口 DevTools**：在创建 `win` 后加 `win.webContents.openDevTools()`
2. **验证 Cookie**：Console 执行
   ```javascript
   document.cookie.split(';').map(s => s.trim()).filter(s => /^SUB(?:=|$)/.test(s) || /^SUBP(?:=|$)/.test(s))
   ```
3. **快速测试登录检测**：授权窗口 Console 执行
   ```javascript
   /创作中心|内容管理|数据中心|发微博|退出登录|我的主页/.test(document.body.innerText)
   ```
4. **验证 DOM 选择器**：
   ```javascript
   // 昵称
   Array.from(document.querySelectorAll('.user-info .name, .username, .WD_header_name, [class*="screen-name"]'))
     .map(e => e.innerText?.trim()).filter(Boolean)
   // 头像 URL
   Array.from(document.querySelectorAll('img[class*="avatar"], a[href*="weibo.com/u/"] img'))
     .map(i => i.src).filter(Boolean).slice(0, 3)
   ```

## 七、未来变更风险点

1. **创作中心 `me.weibo.com` 大版本重构**：历史上微博多次改版（W 版 → V6 → V7 → me.weibo.com），DOM class 命名可能整体替换
2. **登录 cookie 名变化**：`SUB` → 改名时同步更新 detectLoggedIn
3. **微博号展示位置变化**：部分新版创作中心可能不在页面文本里直接显示微博号，需要从 data-* 属性或 XHR 接口获取
4. **头像 CDN 域名切换**：`sinaimg.cn` / `h5.sinaimg.cn` / `weibocdn.com` 三域名实际切换频繁，强制 HTTPS 白名单可能需要追加
5. **发布前风控加强**：新版微博发布前可能要求滑块 / 点击验证，届时发布流程需用户辅助
