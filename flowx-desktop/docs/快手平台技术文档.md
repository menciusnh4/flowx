## 第二章 账号接入

### 2.1 登录态检测（detectLoggedIn）

**检测策略**：
```
1. URL 检测：
   - 未登录：URL 包含 login / signin / passport / sso
   - 已登录：URL 包含 cp.kuaishou.com 且非登录页

2. DOM 辅助检测：
   - 查找用户头像 / 昵称元素
   - 页面文本包含「创作中心」「数据中心」等关键词
```

### 2.2 账号信息提取（extractPageInfo）

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `nickname` | `string` | 昵称 |
| `avatar` | `string` | 头像 URL |
| `platformAccountId` / `userId` | `string` | 快手号 |
| `fansCount` | `number?` | 粉丝数 |
| `followCount` | `number?` | 关注数 |
| `likeCount` | `number?` | 获赞数 |

### 2.3 快手号提取策略

按优先级依次尝试：
1. URL 路径中的用户 ID
2. DOM 中含「快手号」标签的文本提取
3. 页面 body 全文正则匹配

### 2.4 粉丝/关注/获赞数提取

- DOM 元素 class 含 number/count/num 的数字元素 + 兄弟 label 配对
- body 全文正则双向兜底（标签在前 / 标签在后）
- 支持「万 / 千 / 亿」后缀换算

## 第三章 视频发布

### 3.1 发布页 URL

`https://cp.kuaishou.com/article/publish/video`

### 3.2 标准发布流程

```
1. 分区创建发布窗口 + NavigationTracker
2. loadURL 视频发布页 + 导航稳定
3. detectLoggedIn + 未登录显示窗口等 120s
4. 上传视频（CDP FileChooser 方案）
5. 等待上传完成
6. 填写表单（标题/描述/话题等）
7. 点击发布按钮
8. 成功信号轮询
9. 完成
```

### 3.3 视频上传技术方案

使用 CDP 方式上传文件：
- FileChooser 拦截方案
- DOM.setFileInputFiles 兜底方案
- 等待上传完成（进度条消失 / 状态文本变化）

## 第四章 图文发布（image）

### 4.1 发布页 URL 与入口

**图文发布 URL**：`https://cp.kuaishou.com/article/publish/image`

直接通过 URL 参数切换到图文发布模式，省去点击 tab 的步骤。

### 4.2 标准发布流程

```
1. 窗口初始化 + NavigationTracker
2. 导航到图文发布页 + 导航稳定
3. 登录态检测
4. 图片上传（CDP FileChooser）
5. 等待上传完成
6. 填写标题 / 描述 / 话题
7. 点击发布按钮
8. 发布结果检测
9. 完成/清理
```

### 4.3 图文页面结构

快手图文发布页采用标准的 React 前端架构，包含：
- 文件上传区域（拖拽 + 点击上传）
- 标题输入框（React 受控组件）
- 描述/正文输入区域
- 话题标签区域
- 发布按钮

### 4.4 标题填写（React 受控组件）

使用 `document.execCommand('insertText')` 方式确保 React state 同步更新：
```javascript
input.focus();
document.execCommand('selectAll');
document.execCommand('delete');
document.execCommand('insertText', false, text);
```

### 4.5 正文描述填写

与标题填写方式类似，使用 execCommand 方式确保受控组件正确响应。

### 4.6 图片上传技术方案

**双方案**：
1. FileChooser 拦截方案（优先）
2. DOM.setFileInputFiles 兜底方案

上传完成后等待缩略图渲染确认。

### 4.7 发布按钮与结果检测

**发布按钮**：通过文本匹配（"发布"/"立即发布"）+ class 精确匹配定位。

**结果检测**：
- URL 跳转到管理页 / 成功页
- body 文本命中「发布成功」「发布完成」等关键词

## 第六章 排错指南

| 失败现象 | 可能原因 | 排查方法 |
|:---|:---|:---|
| 登录后仍判未登录 | URL 白名单缺失 | 检查 `detectLoggedIn` 日志的 `matchedKeywords` |
| 上传无响应 | FileChooser 未拦截成功 | 检查上传区域的 file input 选择器 |
| 表单填写后丢失 | React 受控组件，没用 execCommand | 确认填写方式为 execCommand |
| 发布按钮找不到 | 页面结构变化 / 按钮在滚动区域外 | 先滚动到页面底部再查找 |
| 发布后无反馈 | 结果检测条件不匹配 | 检查 URL 变化和 body 文本关键词 |
